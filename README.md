# 🤖 Зарплатний Telegram-бот

## Структура файлів

```
salary_bot/
├── bot.py          — головний файл бота
├── workers.py      — список працівників та їх параметри
├── salary.py       — логіка розрахунку зарплати
├── storage.py      — збереження записів у файл
├── config.py       — токен та ID адміна
├── requirements.txt
└── records.json    — створюється автоматично
```

---

## ⚙️ Налаштування (покроково)

### Крок 1 — Отримайте токен бота
1. Відкрийте Telegram, знайдіть **@BotFather**
2. Напишіть `/newbot`
3. Придумайте назву (наприклад: `Зарплата`)
4. Придумайте username (наприклад: `moya_firma_salary_bot`)
5. Скопіюйте отриманий токен

### Крок 2 — Дізнайтесь свій Telegram ID (для адмін-доступу)
1. Напишіть боту **@userinfobot** у Telegram
2. Він покаже ваш ID (число, наприклад: `123456789`)

### Крок 3 — Заповніть config.py
```python
BOT_TOKEN = "1234567890:AAFxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx"
ADMIN_IDS = [123456789]
```

### Крок 4 — Встановіть Python та залежності
```bash
# Встановлення Python (якщо немає): https://python.org
pip install -r requirements.txt
```

### Крок 5 — Запустіть бота
```bash
python bot.py
```

## 🚀 Запуск на безкоштовному сервері (Railway)

1. Зареєструйтесь на [railway.app](https://railway.app)
2. Натисніть **New Project → Deploy from GitHub**
3. Завантажте файли через GitHub або використайте **Deploy from local**
4. У розділі **Variables** додайте: `BOT_TOKEN = ваш_токен`
5. Бот працюватиме 24/7 безкоштовно

## 📱 Команди бота

### Для всіх працівників:
- `/start` — почати розрахунок зарплати

### Для адміністратора:
- `/admin` — зведення по всіх працівниках + загальний фонд
- `/admin_export` — скачати CSV файл з усіма записами
- `/admin_clear` — очистити всі записи (наприклад, після виплати)

## 👥 Зміна працівників

Всі дані про працівників знаходяться у файлі `workers.py`.

**Додати нового працівника виробництва:**
```python
{
    "name": "Нове Ім'я",
    "type": "kg",
    "fixed_extra": 0,   # надбавка в зл (0 якщо немає)
    "bonus": 0,         # стала премія в зл
},
```

**Додати нового продавця:**
```python
{
    "name": "Нове Ім'я",
    "type": "sales",
    "rate": 22,              # ставка за годину
    "multi_point": False,    # True якщо працює на різних точках
    "point": "B",            # точка (A, B або C)
    "threshold": 2000,       # поріг для відсотку (None якщо немає)
    "bonus": 0,              # стала премія
    "fixed_extra": 0,
},
```

## 💡 Логіка розрахунку

**Виробництво:**
```
Зарплата = кг × 9 зл + надбавка + премія
```

**Продажі (з відсотком):**
```
Зарплата = години × ставка + 2% від (продажі - поріг) + премія
           (якщо продажі > порогу, інакше 2% = 0)
```

**Пороги:**
- Точка A → поріг 5 000 зл
- Точки B, C → поріг 2 000 зл
